## 🎓 Что я делаю в QA

| Слой | Что умею |
| --- | --- |
| **Test design** | Test Plans со scope/entry/exit/рисками, Test Cases в стандартном формате (smoke, boundary, negative, exploratory) |
| **Bug reports** | Severity/Priority, шаги воспроизведения, expected vs actual, evidence, root cause, suggested fix |
| **Test automation** | Page Object Model, семантические локаторы (`getByRole`, `getByLabel`, `getByTestId`), без `waitForTimeout` |
| **Test pyramid** | E2E для сквозных сценариев, API для бизнес-правил, Unit для чистых функций |
| **CI / observability** | GitHub Actions с параллельными кубами, Allure, уведомления, артефакты падений |
| **Process** | Traceability требований, ревью PR, документирование known defects |
